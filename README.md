# Музыкальный квиз «Своя игра» (локально)

## Запуск
1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Запустить сервер:

```bash
uvicorn app.app:app --host 0.0.0.0 --port 8000
```

3. Открыть страницы:
- Экран: `http://<IP-ноута>:8000/board`
- Ведущий: `http://<IP-ноута>:8000/host`
- Игроки: `http://<IP-ноута>:8000/player`

## Публичный хостинг на Railway
1. Загрузи проект в GitHub.
2. Создай новый проект в Railway и выбери `Deploy from GitHub repo`.
3. Подключи этот репозиторий.
4. Railway использует файл `railway.json` и сам запустит:

```bash
uvicorn app.app:app --host 0.0.0.0 --port $PORT
```

5. После деплоя открой в Railway `Settings -> Networking -> Generate Domain`.
6. Используй публичные ссылки:
- Ведущий: `https://<your-domain>/host`
- Экран: `https://<your-domain>/board`
- Игроки: `https://<your-domain>/player`

На странице ведущего автоматически показываются ссылка для игроков и QR-код.

## Контент
- Аудио складывай в `static/audio/` (mp3/wav).
- Вопросы и ответы в `data/questions.json`.
- Для финала используй поле `final` в том же JSON и добавь трек `static/audio/final.mp3`.

Формат вопроса:
```json
{"points": 100, "audio": "my_track.mp3", "answer": "Исполнитель - песня"}
```

Формат финала:
```json
{"title": "Финальный раунд", "audio": "final.mp3", "answer": "Правильный ответ"}
```

## Как играть
- Любой игрок нажимает «Ответить».
- Кнопка блокируется, когда кто-то нажал первым, а ведущий при необходимости вручную открывает ее снова кнопкой `Сбросить кнопку`.
- Очки начисляет ведущий вручную, можно удвоить или снять.
- Для финала ведущий нажимает `Запустить финал`, после этого очки скрываются на общем экране.
- Игроки отправляют ставку в пределах своих текущих очков.
- Затем ведущий открывает финальный вопрос, игроки отправляют ответы, а ведущий отмечает каждый ответ как верный или неверный.
- После проверки ведущий нажимает `Показать финальные очки`.

## Что проверить перед вечеринкой
- Открывается публичная страница `/player` с телефона по мобильному интернету.
- На `/host` виден QR-код и он ведет на `/player`.
- Аудио-файлы проигрываются в публичной версии.
- Финальный раунд принимает ставки и скрывает очки до кнопки `Показать финальные очки`.
